Security · Layer 6

Credentials and API security.

A GitHub token and the local console are the two things here worth stealing, so both are encrypted at rest, compared in constant time, and validated before anything trusts them. Verbatim source from the public mcp-server repository.

← Back to the security overview

The threat

A token sitting in plaintext on disk is a credential leak waiting for any other process to find it, and a token echoed into a log is the same leak with a longer fuse. The subtler failures are in the comparison itself: a naive string compare leaks the token's contents through timing, and a Unicode-normalized compare with no format gate lets a homoglyph slip past. All four are closed before the token is ever used.

How a console request is authenticated

The presented token is normalized, format-gated to strict hex, and only then compared in constant time. The expensive checks happen after the cheap rejections, and the timing-safe compare is the last step, not the first. 

{% raw %}flowchart TD
  R[Request arrives] --> EX{Bearer header or SSE token query?}
  EX -- neither --> D401[401: no token]
  EX -- yes --> NF[NFC-normalize the presented token]
  NF --> HEX{Matches strict 64-hex format?}
  HEX -- no --> D401
  HEX -- yes --> LEN{Length equals a stored token?}
  LEN -- no --> D401
  LEN -- yes --> TS[crypto.timingSafeEqual compare]
  TS -- no match --> D401
  TS -- match --> OK[Authenticated, lastUsedAt updated]{% endraw %}

Tokens are encrypted at rest, never logged in full

A GitHub token is validated by format, then encrypted with AES-256-GCM under a key derived from PBKDF2 with a random per-token salt. The stored blob carries its own salt, IV, and auth tag, and the file is written owner-only.

From src/security/tokenManager.ts 

{% raw %}private deriveKey(passphrase: string, salt: Buffer): Buffer {
  return crypto.pbkdf2Sync(passphrase, salt, TokenManager.ITERATIONS, TokenManager.KEY_LENGTH, 'sha256');
}

Any token that reaches a log or an error string is scrubbed by pattern, for every GitHub token shape: 

{% raw %}createSafeErrorMessage(error: string, token?: string): string {
  let safeMessage = error
    .replaceAll(/\bghp_\S+/g, '[REDACTED_PAT]')
    .replaceAll(/\bgithub_pat_\S+/g, '[REDACTED_FINE_PAT]')
    .replaceAll(/\bghs_\S+/g, '[REDACTED_INSTALL]')
    .replaceAll(/\bgho_\S+/g, '[REDACTED_OAUTH]')
    .replaceAll(/\bgh[a-z]_\S+/gi, '[REDACTED_TOKEN]');  // catch any other gh*_ pattern
  return safeMessage;

The console compare is constant-time and Unicode-safe

The strict hex format check runs before timingSafeEqual, so Unicode abuse never reaches the comparison, and a length mismatch short-circuits so the timing-safe path only ever compares equal-length buffers.

From src/web/console/consoleToken.ts and authMiddleware.ts 

{% raw %}const TOKEN_FORMAT = /^[0-9a-f]{64}$/;

verify(presented: string): ConsoleTokenEntry | null {
  if (!this.data || !presented) return null;

  // DMCP-SEC-004: NFC-normalize and strict-format-check before any compare.
  // This blocks Unicode abuse from reaching timingSafeEqual.
  const normalized = UnicodeValidator.normalize(presented).normalizedContent;
  if (!TOKEN_FORMAT.test(normalized)) return null;

  const presentedBuf = Buffer.from(normalized, 'utf8');
  for (const entry of this.data.tokens) {
    const storedBuf = this.tokenBuffers.get(entry.id);
    if (!storedBuf || storedBuf.length !== presentedBuf.length) continue;
    if (timingSafeEqual(presentedBuf, storedBuf)) {
      entry.lastUsedAt = new Date().toISOString();
      return entry;
    }
  }
  return null;
}{% endraw %}

The order is the point again. Normalize, then gate the format, then compare in constant time. Each step exists so the next one only ever sees input it can safely reason about.

Where credentials and API sit in the stack

This layer guards the boundary between the local server and the outside world: the GitHub token used for portfolio sync and collection submission, and the local console that surfaces the Gatekeeper and logs. Rate limiting and the optional TOTP second factor sit on the same boundary. 

{% raw %}flowchart LR
  USER[Local console request] --> AUTH[authMiddleware: normalize + hex gate]
  AUTH --> CT[consoleToken: constant-time verify]
  CT -- "authenticated" --> CONSOLE[Console: permissions, logs, metrics]
  SYNC[Portfolio sync / collection submit] --> TM[tokenManager: decrypt token in memory]
  TM --> RL[Rate limiter + safe downloader]
  RL --> GH[GitHub API]{% endraw %}
